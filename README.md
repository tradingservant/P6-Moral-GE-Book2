# GE Book 2 網上練習：Helping our world

香港小學六年級英語練習，題目用英國英語，畫面用繁體中文。學生可以一邊做，一邊在這一頁看見練習點數。這是靜態網頁，沒有登入，也沒有伺服器記分。

## 這是練習，不是考試

這是課堂和家中用的練習，不是防作弊考試，也不是集中成績系統。

參考答案和可接受答案都寫在前端程式裡。懂得打開開發者工具的人可以看到。

「首次答啱」只表示這一頁記下的第一次提交，不能證明學生沒有事先看過答案。

分數只存在這一頁的記憶體。關閉分頁或重新整理後就會消失。重設也會清掉。不會使用 localStorage、sessionStorage、IndexedDB 或 cookie 保存作答，也不會把答案傳到別處。

老師如果要核對短答，請在課堂直接看學生的螢幕，或請學生先不要重新整理。本站沒有老師後台。

## 題目

核心 57 題，選修 5 題，閱讀短文 1 則不計分。

| 範圍 | 題數 |
| --- | ---: |
| 第 1–7 站（核心） | 57 |
| 第 8 站（選修／非核心，可以略過） | 5 |
| 第四站短文《After the Earthquake》 | 不計分 |

沒有正式 /57 總分。短答四題一律待老師在課堂核對。就算寫法和參考答案一樣，也不會自動當作已經掌握。

單選、填充和多選完全答對才得 1 分，沒有部分分。多選要選滿該題指定的數量，選項集合要完全相同。第一次就答對、而且之前沒有按「提示」，會計入「首次答啱（無提示）」。先看提示再答對，或第一次答錯後再答對，則另外計入「提示後或重做才正確」。這兩項不會合併，重做也不會改寫首次結果。

填充如果自動判為 0 分，可以在本頁按「請老師在課堂看此題」。這只是畫面上的標記，不會把填充改成短答那種待核對，也不算分。

紙本練習和這個網上練習有部分題幹重覆，適宜分開時間做。

## 開啟

用靜態檔案伺服器開啟此資料夾，然後進入首頁。頁內連結都是相對路徑，日後若放在子路徑（例如 `/P6-Moral-GE-Book2/`）也可以運作。這個儲存庫沒有開啟 GitHub Pages，也沒有會在合併時發佈網站的流程。

直接以檔案網址開啟時，部分瀏覽器會禁止載入模組。請改用靜態伺服器，例如：

```bash
python3 -m http.server
```

## 測試

需要 Node.js 22 或以上，以及本機的 Chrome。瀏覽器測試會用無頭 Chrome，不會截圖。

```bash
npm install
npm test
```

如果 Chrome 不在預設位置，可以設定 `CHROME_PATH`。
